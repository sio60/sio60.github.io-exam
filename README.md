# 문학과 인생 중간고사 공부 앱

강남대 「문학과 인생」 중간고사(논술 7문제) 대비용 웹앱.

- **논술 암기**: 교수님 중간시험 예시 문항 7개 + 「7문제 핵심정리」 PDF 예시 답안.
  한 문제씩 ① 읽기 → ② 뼈대 → ③ 빈칸(초성 힌트) → ④ 첫 글자 → ⑤ 통째로 쓰기(핵심어 채점)
- **배우기**: 1~7주차 레슨, 중간중간 문제. 난이도 상 · 중 · 하
- **퀴즈·카드**: 레슨별 / 전체 섞기, 암기 카드
- **오답노트**: 틀린 문제 자동 저장, 2번 연속 맞히면 졸업
- **공부법**: 인출 연습·분산 학습 연구와 시험장 전략 (출처 포함)

진행 기록은 브라우저(localStorage)에만 저장된다.

논술 답안은 `memo.js`, 나머지 내용은 `data.js`를 고치면 된다.
