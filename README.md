# 문학과 인생 중간고사 공부 앱

강남대 「문학과 인생」 1~7주차 중간고사 대비용 웹앱.

- 처음에 난이도 **상 · 중 · 하** 선택 (언제든 바꿀 수 있음)
- **배우기**: 5살 설명 → 개념 카드 → 중간중간 문제
- **퀴즈**: 레슨별 / 전체 섞기
- **암기 카드**: 모름 · 헷갈림 · 앎 3칸
- **오답노트**: 틀린 문제 자동 저장, 2번 연속 맞히면 졸업
- **서술형**: 교수님 시험 예시 7문항 직접 쓰고 키워드 채점 + 모범 답안
- **공부법**: 인출 연습·분산 학습 연구와 시험장 전략 (출처 포함)

진행 기록은 브라우저(localStorage)에만 저장된다.

내용 수정은 `data.js`만 고치면 된다.
